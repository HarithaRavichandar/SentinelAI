# Inference Module Documentation

## Purpose

The **sentinelai.inference** module provides a reusable, production‑ready inference engine for the pre‑trained balanced Random Forest model (`random_forest_balanced.pkl`). It encapsulates model loading, preprocessing (scaling), strict input validation, and prediction logic behind a simple Python API.

## Architecture

- **Model loading** – The module loads the serialized `RandomForestClassifier` from `data/models/random_forest_balanced.pkl` using `joblib`.
- **Preprocessor loading** – The matching preprocessing artifact (`preprocessor_balanced.pkl`) contains a `StandardScaler` (or similar) and the ordered list of feature column names.  The scaler is loaded and **not** re‑fitted.
- **Feature validation** – Input must be a `dict` mapping **exactly** the 76 expected feature names to numeric values.  Missing, extra, non‑numeric, boolean, NaN, or infinite values raise a clear `ValueError`.
- **Prediction** – After validation the scaler transforms the feature vector and the model predicts the class ID.  If the model implements `predict_proba`, a probability map keyed by the actual class IDs (`model.classes_`) is returned.

## Required Input Features

The inference engine expects **all 76 features** in the order stored in the preprocessor payload.  The feature names can be inspected programmatically via:
```python
engine = InferenceEngine()
print(engine.columns)  # list of expected feature names
```
Do **not** include the target label (e.g., `Label`) among the input features.

## Validation Rules

| Rule | Description |
|------|-------------|
| **Type** | Input must be a `dict`.
| **Completeness** | All expected columns must be present; missing columns raise `ValueError`.
| **No extras** | Unexpected keys raise `ValueError`.
| **Numeric** | Values must be `int`, `float`, or NumPy numeric types. Booleans are rejected.
| **Finite** | Values cannot be `NaN`, `inf`, or `-inf`.

## CLI Usage (Smoke Test)

A minimal command‑line entry point is provided in `scripts/smoke_test_inference.py`:
```bash
python -m scripts.smoke_test_inference
```
It loads a sample JSON fixture (`tests/fixtures/sample_features.json`), runs a prediction, and prints the results.

## Extensibility

- To add new models, update `MODEL_PATH` and `PREPROC_PATH` constants.
- The probability mapping uses `model.classes_` to stay robust even if class ordering changes.
